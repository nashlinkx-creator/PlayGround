# PlayGround

## THRASH PARK — 2 Minute Trick Run

A self-contained 3D skate park game built with Three.js. Drop into Sunset Valley, link grinds, manuals, grabs and flip tricks, and bank one huge combo before the two-minute clock runs out.

**Controls**

| Action | Keyboard |
| --- | --- |
| Ride / push | `W A S D` or arrow keys |
| Charge & release ollie | `Space` |
| Kickflip / heelflip / shove-it | `J` / `K` / `L` |
| Grab | `G` |
| Manual | `C` |
| Pause | `Esc` / `P` |

On touch devices use the on-screen joystick and trick buttons. Touch the board to start.

**Run it locally**

```bash
python3 -m http.server 3002
# then open http://localhost:3002/
```

No build step and no network requests are required at runtime: Three.js, fonts and all art are bundled or generated procedurally. Best score is stored in `localStorage` under `thrashpark.best`.
